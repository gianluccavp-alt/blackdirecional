# Simulador Black Friday – Pró-Soluto

Simulador para corretores compararem o Pró-Soluto na condição normal (até 84x, com correção de 0,5% a.m. em obra e 1,5% a.m. pós-obra, parcelas fixas pelo sistema Price) com a condição Black Friday (até 60x sem juros).

Basta abrir `index.html` no navegador ou acessar o link do GitHub Pages do repositório.
